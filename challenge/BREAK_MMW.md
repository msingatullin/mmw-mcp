# MMW Global Developer Challenge 2026/2027

**Status: preparation only — Kaggle hackathon is not launched.**
Official platform: https://mmwhub.tech
English documentation: https://docs.mmwhub.tech

## Contributor workflow
1. Read the published challenge rules before any testing.
2. Pick an issue marked for this challenge, or propose an original discovery.
3. Fork this repository; create a feature branch in your own fork.
4. Use only your own authorized TECH accounts and synthetic data, respecting published quotas.
5. Make reproducible tests, implementation or written evidence, then submit a pull request where code changes are relevant.
6. Submit your Kaggle writeup with the relevant GitHub issue/PR links and evidence of real MMW interactions.
7. Do not publish tokens, other people's data, private security findings, or exploit details.

Security findings must be disclosed privately via an approved channel, not through public issues or pull requests.
No destructive tests, stress tests, or production modifications without separate written authorization.
AI Archivist availability on TECH is pending verification and enablement; do not claim it is accessible today.

## Awards proposed by the organizer
- 1st place: lifetime unlimited MMW access.
- 2nd and 3rd: 24 months unlimited MMW access.
- 4th–10th: 12 months unlimited MMW access.
These are organizer-approved prize tiers in preparation; final terms and eligibility will be defined in the Kaggle rules before launch. Third-party paid model costs are excluded.

## Submission evidence
Provide reproducible steps, expected/actual behavior or before/after measurements, scrubbed logs, source code when relevant, proof of actual MMW API/MCP use, and a concise explanation of user impact.

## Break MMW
Scope: safe functional tests of write/search/read/update/delete, relevance, tenant isolation in self-owned test accounts, error responses, long-query ranking, and API contract. No public security vulnerability details. Good discoveries include minimal reproduction and evidence.
