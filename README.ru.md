# MMW — единая память для AI-ассистентов

**Общая память AI-агентов: с источниками записей и видимыми противоречиями.**

Сохраните решение в ChatGPT, найдите ту же запись в Codex или привязанном Telegram. Контекст не приходится каждый раз копировать в новый чат.

[Быстрый старт](https://docs.mmwhub.ru/start/quickstart/) · [Создать аккаунт](https://app.mmwhub.ru/signup) · [Документация](https://docs.mmwhub.ru/) · [English](README.md)

## Что доступно

- Общая память подключённых клиентов в одном разрешённом аккаунте, проекте и workspace. Ключи разных клиентов могут отличаться.
- Источники записей, признаки устаревания и противоречий, явная проверка актуальных фактов. Дата загрузки и ответ модели не доказывают актуальность.
- AI-Архивариус MMW: автоматическая организация новых допустимых записей для аккаунтов с необходимым основанием обработки. Действуют настройки приватности и ограничения доступа. AI-помощник MMW помогает сформулировать вопрос при конфликте, решение принимает человек. [Границы обработки](https://docs.mmwhub.ru/memory/archivist/).
- Подключение приложений через MCP, управление записями и доступом в кабинете. Организации подключаются отдельно, а не автоматически для каждого Free-аккаунта.

MMW — платформа. В этом репозитории находится **открытый набор подключения, а не приватный backend**. Лицензия MIT относится к файлам репозитория.

MMW не читает все ваши чаты самостоятельно. Загрузка локальных сессий требует отдельного согласия. `scope=shared` — метка фильтра, а не разрешение доступа. Источник записи не доказывает её истинность. Не сохраняйте секреты: автоматическая очистка не гарантирует обнаружение каждого ключа или пароля.

## Подключение за три шага

1. [Зарегистрируйтесь и подтвердите почту](https://app.mmwhub.ru/signup). Стартовый Free-аккаунт создаётся автоматически: **3 дня**, без карты и обязательного выбора платного тарифа.
2. Подключите первый клиент, затем второй к **тому же проекту**. Для OAuth и прямого MCP локальный агент не требуется.
3. Сохраните вымышленную тестовую заметку и найдите её из второго клиента.

Первый клиент:

```text
Сохрани в MMW отдельную тестовую заметку:
MMWFIRSTCHECK7429. Решение: отчёт команды готовим по пятницам.
workspace=default, scope=shared, source_id=first-memory-check-7429.
Верни ID записи.
```

Второй клиент:

```text
Найди через MMW метку MMWFIRSTCHECK7429 в workspace default.
Верни исходные ID и source_id. Если записи нет, не угадывай.
```

Сравните **ID и source_id**: похожего текста недостаточно. В привязанном Telegram используйте `/find MMWFIRSTCHECK7429`. После проверки удалите только тестовую запись по возвращённому ID.

### ChatGPT и веб-клиенты: OAuth

Подключите [официальное приложение MMW в ChatGPT](https://chatgpt.com/plugins/plugin_asdk_app_6ac22b6361d481919cbaecd880a4c9ca), если оно доступно вашему аккаунту. Разрешите нужный проект на странице MMW. Установка агента не нужна. Доступность зависит от настроек и тарифа клиента.

Другие веб-клиенты с поддержкой удалённого MCP используют `https://mcp.mmwhub.ru/mcp` и свой процесс OAuth. [ChatGPT](https://docs.mmwhub.ru/clients/chatgpt/) · [Claude в браузере](https://docs.mmwhub.ru/clients/claude-web/).

### Codex, Cursor и прямой MCP

Адрес: **`https://mcp.mmwhub.ru/mcp`**. Создайте ключ нужного проекта в кабинете и введите его через защищённый локальный механизм клиента. Не отправляйте ключ в чат, поддержку, журнал или публичный Git.

Конфигурация Codex — TOML:

```toml
[mcp_servers.mmw]
url = "https://mcp.mmwhub.ru/mcp"
bearer_token_env_var = "MMW_API_KEY"
```

Временный ввод в Bash без значения ключа в истории команд:

```bash
read -rsp 'MMW API key: ' MMW_API_KEY; echo
export MMW_API_KEY
codex
```

Для постоянной работы используйте защищённое хранилище клиента. У JSON-клиентов другой формат настроек. [Codex](https://docs.mmwhub.ru/clients/codex/) · [Cursor](https://docs.mmwhub.ru/clients/cursor/) · [Все клиенты](https://docs.mmwhub.ru/clients/overview/).

### Локальный агент: только при необходимости

`mmw-agent` нужен клиентам со stdio или для добровольной загрузки сессий. Требуются Python 3.11+ и [uv](https://docs.astral.sh/uv/). Актуальная версия и команды находятся в [единой инструкции](https://docs.mmwhub.ru/agent/overview/); wheel распространяется MMW, не через PyPI.

Setup запрашивает ключ локально. Обычные сохранение и поиск работают без загрузки истории. `mmw-agent consent` разрешает загрузку, `mmw-agent revoke` останавливает её. Это отдельные действия от удаления сохранённых записей и управления серверной AI-обработкой в разделе «Приватность».

## Инструменты

| Инструмент | Назначение |
| :--- | :--- |
| `remember` | Сохранить запись и сведения об источнике. |
| `search` | Найти разрешённые записи, проверить происхождение и статусы. |
| `validate_memory` | Сравнить записи с переданным актуальным хешем источника. |
| `forget` | Удалить запись или разрешённые записи источника. |
| `preview_search`, `read_memory` | Краткий поиск и чтение записи, если доступны в профиле клиента. |
| `search_history` | Поиск загруженных сессий при поддержке подключения и наличии доступа. Не открывает несинхронизированные чаты. |

Состав проверяйте через `tools/list`: каталог приложений, прямой MCP и локальный агент могут показывать разные наборы. `gateway_call` и экспериментальная внешняя отправка не входят в обычный сценарий памяти Core. Видимая схема не доказывает работоспособность интеграции.

[Полный справочник](https://docs.mmwhub.ru/reference/mcp-tools/) · [Источники и актуальность](https://docs.mmwhub.ru/memory/source-and-freshness/) · [Если клиенты видят разное](https://docs.mmwhub.ru/guide/shared-memory/).

## Доступ, приватность и ограничения

Сервер проверяет авторизацию и права проекта/организации. Не ослабляйте их для проверки подключения. Автоматическая организация может использовать внешнюю AI-обработку на применимых условиях сервиса; настройки приватности сохраняются. Ответ модели не подтверждает факт автоматически.

[Безопасность](https://docs.mmwhub.ru/account/security/) · [Данные и удаление](https://docs.mmwhub.ru/account/data-and-deletion/). Удаление из рабочей памяти и хранение в существующем архиве — разные операции.

Free и платные тарифы имеют лимиты, Enterprise не является безлимитным. Цены в рублях, способы оплаты и текущие ограничения проверяйте [на сайте](https://mmwhub.ru/#pricing) и в кабинете. Полный снимок релиза не означает регулярное резервирование всего содержимого каждого тарифа. Сохраняйте собственные копии важных данных.

## Старые скрипты подключения

`connect.sh` и `connect.ps1` не устанавливают mmw-agent. Перед запуском прочитайте [предупреждения в английской инструкции](README.md#connect-kit-connectsh-connectps1): они могут перезаписывать конфигурационные файлы целиком; `--uninstall` удаляет созданные файлы, а не только секцию MMW. Выбирайте конкретный клиент и сохраняйте его конфигурацию заранее. Старый `mmw_proxy.py` больше не поддерживается.
