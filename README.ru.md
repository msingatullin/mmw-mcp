# MMW — память для ИИ-помощников, которой можно доверять

[![Protocol](https://img.shields.io/badge/MCP-Streamable%20HTTP-blue?style=flat-square)](https://modelcontextprotocol.io)

Одна память на все ИИ-программы — и она сама находит, где факты в ней противоречат друг другу.

Сайт: **https://mmwhub.ru** · Документация: **https://docs.mmwhub.ru** · English: [README.md](README.md)

## Зачем это

ИИ-помощник опасен не тогда, когда забывает, а когда уверенно помнит старое. В памяти лежат две записи — «ИНН …001» и «ИНН …002», — и агент берёт первую попавшуюся. MMW построен вокруг этой проблемы:

- **Противоречия видны, а не спрятаны.** Записи с одним ключом факта, которые расходятся, помечаются как противоречие. Поиск отдаёт агенту самую новую версию, у старых есть ссылка на неё. В кабинете каждое расхождение — один простой вопрос «какая запись верная?» с вариантами рядом; кнопка «Помочь разобраться» просит языковую модель сформулировать вопрос. Решает человек, ничего не перезаписывается молча.
- **Паспорт факта.** У каждой записи видно, откуда она взята, когда, хеш источника, все версии этого факта и что её заменило.
- **Привязка к источнику.** Если запись сделана из файла, локальный агент сам считает его хеш; файл изменился — запись помечается устаревшей.
- **Одна память везде.** Claude Code, Cursor, Codex, Claude Desktop, claude.ai, ChatGPT, Telegram-бот @mmwhub_bot и навык Алисы «Память MMW» работают с одной памятью. В кабинете видно, какие программы подключены и когда были на связи.
- **Данные в России.** Серверы в Москве, оплата в рублях.

## Как подключить

1. Зарегистрируйтесь на https://app.mmwhub.ru и подтвердите почту. Тариф Free — 3 дня без карты.
2. Скопируйте API-ключ (начинается с `mmw_`). Он показывается один раз — сохраните его в менеджере паролей.
3. Подключите программу и перезапустите её.

**Claude Code** (нужны Python 3.11+ и [uv](https://docs.astral.sh/uv/)):

```bash
claude mcp add mmw -s user \
  -e MMW_API_KEY=mmw_ваш_ключ \
  -- uvx --from https://app.mmwhub.ru/downloads/mmw-agent/mmw_agent-0.1.6-py3-none-any.whl mmw-agent
```

**Cursor, Claude Desktop, Codex, ChatGPT, VS Code, Telegram, Алиса** — пошагово в документации: https://docs.mmwhub.ru/clients/overview/

Проверка: попросите агента «Запомни в MMW: staging выкатываем через systemd-юнит app-staging», а в новой сессии — «Найди в MMW, как выкатывать staging».

## Инструменты MCP

| Инструмент | Что делает |
| :--- | :--- |
| `remember` | Сохранить запись: текст, источник, ключ факта. |
| `search` | Найти записи; у каждой — статус (`unverified`, `stale`, `conflict`) и источник. |
| `forget` | Удалить запись или все записи источника (мягко, факт удаления остаётся в журнале). |
| `validate_memory` | Сверить записи источника с его текущим хешем. |
| `gateway_call` | Вызвать инструмент подключённой интеграции; секреты интеграций не уходят агенту. |
| `mmw_sync_status` | Только в локальном агенте: состояние загрузки истории сессий (по согласию). |

## Безопасность

- Ключи, токены и пароли вычищаются из записей до сохранения.
- Ключ API показывается один раз; на сервере хранится только его хеш.
- Журналы операций не содержат текста записей.
- История сессий загружается только после согласия человека в терминале (`mmw-agent consent`).
